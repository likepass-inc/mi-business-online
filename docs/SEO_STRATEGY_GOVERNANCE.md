# SEO／クエリ戦略 — 運用ガバナンス（四半期レビュー）

GSC・GA4 を前提に、**戦略的クエリの再定義**と**法人需要の仮説・計測**を継続的に揃えるための固定アジェンダです。月次は軽量、四半期で本論とします。

## 四半期レビュー（目安 90 分）

### 1. オープニング（10 分）

- 前期の結論・未決事項の確認
- 本四半期のビジネス優先（キャンペーン・新商品・法人施策）の共有

### 2. 戦略クエリ一覧（25 分）

**目的**: キーワード単位の「役割」と優先度を揃える。

| 論点 | 確認すること |
|------|----------------|
| クラスター | 認知／比較／CV など、クエリ群の役割ラベル |
| 優先度 | 伸長注力 vs 維持 vs 撤退候補 |
| 汎用 KW | 「コーヒーギフト」「紅茶ギフト」等の**法人意図が薄い可能性**のある語の扱い（記事・ショップ・LP の役割分担） |
| 通年 vs 季節 | お歳暮／お中元等への依存度と、通年で伸ばしたいテーマの割当 |

**アウトプット**: 更新版「戦略クエリ一覧」（スプレッドシートや Notion で可。リポジトリ必須ではない）。

### 3. データレビュー（25 分）

- **GSC**: 包括レポートの伸長クエリ・減少クエリ、季節／通年比率（[`COMPREHENSIVE_REPORT.md`](COMPREHENSIVE_REPORT.md) 生成物）
- **GA4**: チャネル・デバイス・購入完了の前年比。法人プロキシの仮説に沿ったイベントが取れているか（[`GA4_CORPORATE_INTENT_PROXY.md`](GA4_CORPORATE_INTENT_PROXY.md)）

### 4. 法人意図の仮説・計測ギャップ（20 分）

**目的**: 「GSC のクエリ行だけでは法人需要を断定できない」前提で、足りない計測を列挙する。

| 論点 | 例 |
|------|-----|
| 仮説 | マガジン流入後の商業ページ遷移、まとめ買い、見積・問い合わせ |
| ギャップ | イベント未計測、カスタム定義なし、クエリとセッションの紐付けに BigQuery が必要 等 |
| 次の一手 | GA4 管理画面でのイベント追加、探索レポート、次四半期の BigQuery 検討 |

**アウトプット**: 「計測ギャップと次タスク」3 件以内（オーナー・期限）。

### 5. クロージング（10 分）

- 次四半期の KPI・実験（コンテンツ・内部リンク・計測）の合意
- 次回日程

## 月次（軽量・30 分目安）

- [`npm run report:comprehensive`](COMPREHENSIVE_REPORT.md) または API で JSON／Markdown を確認
- 戦略クエリ一覧への追記は「明らかな変化があったとき」のみ
