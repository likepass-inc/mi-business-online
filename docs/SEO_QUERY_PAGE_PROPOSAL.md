# 検索クエリ・ランディングページ 提案書（データドリブン）

本書は、GSC の実データ（包括レポートと同一ロジック）に基づき、**伸長注力・通年開拓・汎用キーワードと法人意図**の観点からクエリとページの優先度を整理した提案です。数値の詳細な表は [COMPREHENSIVE_REPORT.md](COMPREHENSIVE_REPORT.md) の実データスナップショットを参照してください。

## データの前提

| 項目 | 内容 |
|------|------|
| 対象期間（現在） | 2026-03-16 〜 2026-04-14（終端オフセット 1 日・直近 30 日相当） |
| 前年同期 | 2025-03-16 〜 2025-04-14 |
| 主要指標 | GSC: クリック・インプレッション・CTR・掲載順位（クエリ／ページ次元） |
| 更新方法 | `npx tsx scripts/export-comprehensive-for-docs.ts` でスナップショット再取得後、本書の「根拠データ」欄を手動またはレビューで追随 |

**解釈上の注意**

- 前年同期比で「クリックは減少・インプレッションは増加」のときは、**順位帯の変化や SERP の変化、CTR の変動**が重なっている可能性があります。単一指標での断定は避け、四半期トレンドで確認してください。
- 汎用ギフト系（コーヒー／紅茶など）は **GSC では流入の事実**まで。法人としての購買に近いかは [GA4_CORPORATE_INTENT_PROXY.md](GA4_CORPORATE_INTENT_PROXY.md) のプロキシで別途検証します。

## 1. 全体サマリー（この期間の読み）

- **サイト全体（GSC）**: クリックは前年比で減少一方、インプレッションは増加、平均掲載順位は改善傾向。検索での**露出は拡大**しているが、**CTR の低下**がクリック減に寄与している可能性が高いです（スナップショット参照）。
- **マガジン（GSC `/magazine/`）**: クリックは前年比で減少、インプレッションは微増、平均順位は改善。記事横の**スニペット最適化・タイトル・意図の一致**が継続テーマです。
- **GA4（参考）**: 同一期間のセッションは前年より減少する一方、購入完了・売上は前年を上回るスナップショットです。オーガニック以外（Direct 等）の寄与も含むため、**クエリ単位の因果**と混同しないでください。

## 2. クエリ提案（優先度つき）

### A. 伸長・勢いを優先してリソースを向ける（戦略方針に合致）

前年同期よりクリックが増え、**増加幅が大きい**クエリを「伸長シード」として優先します。挽回より**コンテンツ強化・内部リンク・関連商品の見せ方**に投下します。

| クエリ（例） | 根拠データ（当該スナップショット） | 提案アクション |
|--------------|-----------------------------------|----------------|
| `香典返し` | 伸長リスト上位（前年 0 → 現在 580 クリック規模） | マガジン／LP の役割分担を確認し、法事・弔事系の導線と商品の一貫性を維持 |
| `紅茶 ギフト` | 前年比 **+260% 超**の伸長 | 通年で扱える汎用カテゴリの代表。**法人シーンのコピー・事例**を検討（GA4 で CV プロキシ確認） |
| `昇進祝い 女性` | 前年比 **+160% 超**の伸長 | シーン特化の継続更新、季節に依存しにくい「祝い・異動」クラスターとして位置づけ |
| `昇進祝い` | マガジン上位で前年比大幅増（スナップショットでは +2000% 級の表記） | ボリューム急増中のため、**検索意図（個人 vs 職場の手土産）**の整理とページ満足度の確認 |
| `コーヒー ギフト` / `コーヒーギフト` / `コーヒー ギフト おしゃれ` / `コーヒー ギフト 高級` 等 | 伸長リストでクラスターとして多数 | 下記「汎用飲料ギフト」セクションを参照 |

**マガジン内の通年比率（参考）**: 当該期間のクエリ行では、ルールベースの季節語ヒットはクリックの **約 0.3%**、通年寄りが **約 99.7%**（マガジン GSC スナップショット）。季節依存の偏りは小さく見える一方、**個別クエリの季節性**は別途キーワード計画で確認してください。

### B. 下落が大きいが「挽回か撤退か」を議論する（一覧は参考）

`退職 お菓子` 系など、前年クリックが大きかったが減少幅も大きいクエリは、**無差別な挽回はコストが高い**ため、四半期レビュー（[SEO_STRATEGY_GOVERNANCE.md](SEO_STRATEGY_GOVERNANCE.md)）で次を決めます。

- 検索意図の変化（SERP の情報型化、競合動画・地図等）の調査
- 記事の再編集・統合・リダイレクトの是非
- 伸長クエリ（A）への内部リンク・リソースの再配分

### C. 汎用飲料ギフトクラスター（「コーヒー」「紅茶」）— 法人意図の設計が必要

| 論点 | 提案 |
|------|------|
| 現状の見立て | GSC 上はマガジン経由で流入・クリックを獲得している一方、**法人としての購買意図は薄い可能性**がある（検索意図が混在）。 |
| クエリ上の対応 | 表記ゆれ（`コーヒー ギフト` と `コーヒーギフト`）を**クラスター**として管理し、意図別（贈答・自宅用・職場・大量購入）の仮説を立てる。 |
| 計測 | GA4 で **ランディング別の商業ページ遷移・CV** を見る（[GA4_CORPORATE_INTENT_PROXY.md](GA4_CORPORATE_INTENT_PROXY.md)）。必要なら **query + page** 次元の GSC 追加取得で「記事 vs ショップ」の内訳を次フェーズで検討。 |

## 3. ページ（URL）提案（優先度つき）

### 伸長が大きいページ（強化・横展開の候補）

| URL（例） | 根拠 | 提案 |
|-----------|------|------|
| `.../magazine/article/4184` | 前年 300 → 現在 2,206 クリック（**+635%** 級） | 当該テーマの検索意図に合わせた更新頻度・関連商品の強化。成功要因の他記事への横展開 |
| `.../magazine/article/4373` | 前年比で大きく増加 | 同様にテーマ分析と内部リンク |
| `.../magazine/article/2345` | 前年 0 → 現在 1,194 クリック（新規立ち上がり） | 新規ニーズの可能性。コンテンツの維持とカニバリゼーション確認 |
| `.../shop/c/c01_iP04/` | カテゴリ別で伸長 | マガジンからの導線とカテゴリの表示順・フィルタの最適化 |

### クリック減少幅が大きいページ（要因分析・優先度付け）

| URL（例） | 根拠 | 提案 |
|-----------|------|------|
| `.../magazine/article/2638` | 前年比でクリック減少幅が最大級 | 順位・SERP・タイトル・競合の変化を調査。更新計画を四半期アジェンダに |
| `.../magazine/article/5264` | 前年比で大きく減少 | 同上 |
| `.../magazine/article/315` / `3033` | マガジンの主力記事で減少 | 退職・お菓子系クエリ全体の下落と連動している可能性。A/B のクエリとセットで検討 |

### ショップ／特集 URL

- `.../shop/i/iP04?occasion=temiyage` 等は減少リストに含まれる場合があります。**手土産・お詫び**の意図と商品棚の整合、マガジンからの導線を [GA4_CORPORATE_INTENT_PROXY.md](GA4_CORPORATE_INTENT_PROXY.md) のプロキシで確認してください。
