## 1. 概要

現在、ダッシュボード（https://mi-business-online.onrender.com/）の「画像リサイズ」機能では、1 回あたり **30 枚まで・50MB まで** の ZIP ファイルをご利用いただいております。数千枚・数 GB 規模の ZIP には対応しておりません。

本提案では、**Cloudflare R2** に大きな ZIP をアップロードいただき、**既存のダッシュボード** 上でジョブ登録・進捗確認・結果ダウンロードまで行える「**大容量バッチ**」機能を追加するものです。処理は既存の Render 環境で実行し、画像枚数に応じた **従量課金（1 枚 70 円）** でご利用いただく想定です。

---

## 2. ご提案内容（機能・構成）

### 2.1 利用フロー（ユーザー視点）

1. ダッシュボードの「画像リサイズ」画面から **「大容量バッチ」** を選択します。
2. 大きな ZIP ファイル（例: 4,000 枚・2.58GB）を選択し、**アップロード**（Cloudflare R2 に直接送信）します。
3. ジョブ登録後、画面で **完了まで待機** します（進捗は画面上で確認可能です）。
4. 完了したら、リサイズ済みの ZIP を **1 ファイルでダウンロード** します。

### 2.2 技術構成（簡易説明）

| 項目 | 内容 |
|------|------|
| **ストレージ** | Cloudflare R2（入力 ZIP・出力 ZIP の保存） |
| **画面・API** | 現行の Render ダッシュボードを拡張（既存の画像リサイズページに「大容量バッチ」セクションを追加） |
| **処理** | 同じ Render 上でバックグラウンド実行。アスペクト比維持・余白付きの 2 サイズ出力は現行仕様どおり |

### 2.3 制限・前提

- 1 ジョブあたりの **最大画像枚数** を設けます（目安: 5,000 枚）。
- 処理時間は枚数に依存します（目安: 4,000 枚で 20〜40 分程度）。完了まではブラウザでポーリング表示となります。
