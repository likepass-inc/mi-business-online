# 競合キーワード分析: オフィスギフト（法人・B2B寄り）

## データソース

- ファイル: `競合/www.officegift.jp-organic-keywords-subdomai_2026-04-21_08-55-21.csv`
- 対象サイト: [オフィスギフト（officegift.jp）](https://www.officegift.jp/)（Webカタログギフト、開業・移転・昇進など用途別訴求が強い競合）
- 主要指標: Ahrefs想定の `Volume`（月間検索ボリューム）、`Current organic traffic`（現在のオーガニック流入想定）

## 分析の前提

- クエリ文言に「法人」「会社」が無くても、**取引先・事務所・就任・景品**などは法人利用シーンと重なるため「法人向け候補」として扱う。
- 「開店祝い」単体は B2C も多いが、**飲食店×開店・カタログギフト×開店**などは競合がコラムで取っており、法人ギフト文脈と接続しやすい。
- 三越伊勢丹法人オンラインでは、**自社GSCの同一語の有無・順位**を照合したうえで優先度を確定すること（本書は競合側の機会示唆）。

## 三越伊勢丹法人オンラインで強化を検討するキーワード（提案）

優先は **(a) 通年または複数シーズンで需要がある**、(b) **法人の購買プロセスに近い**、(c) **自社カタログ・高単価ギフトと接続しやすい** 語に絞る。

| 優先度 | 強化候補キーワード・クラスタ | 理由 |
|--------|------------------------------|------|
| 高 | **社長就任祝い**、**社長就任祝い 取引先**、**役員就任 お祝い プレゼント** | 単語ボリューム・競合流入ともに大きく、法人ギフトのコアシーン。 |
| 高 | **就任祝い**、**昇進 挨拶**、**昇格 挨拶**、**昇進挨拶**（短文・ユーモア等の派生含む） | 通年。記事→商品の導線と `SEO_QUARTERLY_REVIEW` の昇進祝い強化方針と一致。 |
| 高 | **新社屋 お祝い**、**事務所移転祝い**、**移転祝い 花以外**、**事務所開き のし・表書き** | 競合が強い実務系。表書き・相場・品目の権威コンテンツで対抗可能。 |
| 中-高 | **カタログギフト 5万円 / 10万円 / 高級**、**家電 カタログギフト**、**開店祝い カタログギフト** | 価格・カテゴリ横断のハブが競合の受け皿。法人サイトの商品構成とマッピングしやすい。 |
| 中-高 | **年末の挨拶 取引先**、**会社 年末挨拶**、**お歳暮 取引先** | 季節寄りだが規模大。Q4に向けた先行コンテンツ・更新サイクルに載せる価値あり。 |
| 中 | **ビンゴ 景品 1万円**、**景品 3000円**、**忘年会 景品**、**ゴルフコンペ景品** | 社内イベント需要。カタログ・汎用ギフトの法人プロキシ検証とセットで扱う。 |
